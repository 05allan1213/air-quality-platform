## 1. 视觉语言

**Clear Sky Glass · 晴空玻璃。** 开页先看清「哪个对象、哪个时刻、测到了什么」，再看分布、趋势和证据。浅蓝光从静止的天空背景透过工具表面，数据落在安静的云白底上。用户端以地图或查询结果为视觉中心，管理端把空间留给账本、证据和动作。两端共用一套颜色、字阶和焦点语言。

保留首页的不等宽地图构图、轻盈侧栏、玻璃内容面板与较高信息密度。首版采用浅色。冷灰 SaaS、大屏霓虹、重反射、全站风景照片、营销式巨幅标题及用图片代替控件均排除在当前方向之外。Apple 对功能层和内容层的区分指导材质分工。Web 采用填充、边缘、投影与有限模糊，原生 Liquid Glass 的实时折射、环境采样与形变由系统渲染。[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) · [WWDC25 材质演示与逐字稿](https://developer.apple.com/videos/play/wwdc2025/219/)

§3 的玻璃参数是实现起点。保留 §2 配色，根据背景、阅读时长与控件位置调整透明度、模糊、高光和投影，用实际浏览器核对工具浮于内容、云白表面承托读数的效果。实体回退仍沿用这套色义和层次，常规主题避免全白底或所有表面同强度的毛玻璃。

## 2. 颜色与语义 Token

下列短名是**角色名**。正式主题可用 `--aq-` 前缀，基础色供语义角色引用，组件只消费语义角色。尺寸均为 CSS px 的设计参考，字体实现应尊重用户字号。数值来自本项目。

| 角色 | 值、用途与状态 |
|---|---|
| `canvas` / `surface-secondary` | 实测天空以 `#b2d8ed → #d0e6f4 → #b9d9ee → #d8eaf5` 为底。稳定分组用 `#e6f0f7`（候选），表头用 `#dceaf5`（实测）。导航、内容及临时表面见 §3。 |
| `text-primary` / `secondary` / `muted` | 标题、正文 `#142f47`，辅助正文 `#405f75`（实测）。低强调时间或单位 `#48667a`（候选，仅在浅色稳定底上）。较低层级先调字重，再调颜色。 |
| `brand` / `link` / `hover` / `pressed` | 实心主动作 `#0865b8`，链接 `#075aa4` 延续首页。实心悬停 `#075aa4`，按下 `#074e91`（候选），白字。透明动作悬停使用 `#f5fcff` 与链接色。正文链接应有颜色以外的线索。 |
| `selected-strong` / `selected-soft` | 候选强选中 `155deg, #1674c5 → #0865b8`，用于导航或分段。实测浅端 `#177bce` 配纯白的端点对比约 4.41∶1，新浅端约 4.84∶1，仍须在真实字形位置取样。行/选项采用 `#d7e9f6`、深字 `#124f80`，配勾或侧标。 |
| `border-subtle` / `control` / `focus` | 实测分隔 `rgb(61 102 134 / 17%)`，字段边 `#acc6d8`，焦点 `#095e9f`。候选交互深边 `#54768e` 用于轮廓是唯一控件线索之处。弱边只作装饰。焦点环 2px，外偏 2px。若边缘裁切，浅底用深蓝内环，品牌实底用白色内环。跨明暗表面可用白色内圈配 `#095e9f` 外圈，并在相邻实色上核 ≥3∶1。 |
| `success` / `warning` / `danger` | 候选前景/背景分别为 `#126a50 / #e4f3ea`、`#825118 / #f6efda`、`#923739 / #f9e7e8`。分别配完成标记、提示符、错误或危险动作名称。危险实心按钮用 `#923739` 配白字。 |
| `info` / `unknown` | 候选 `#095e9f / #e6f3ff`、`#435f72 / #e4edf4`。未知、受限和缺测可共用中性底，各配不同文字和图形，避免透露受限对象。 |

**四套色义各自维护。** 品牌蓝指可操作或正在选择，系统色指运行和质量，序列色编码数据，AQI 色表达**已核标准**下的等级。蓝色折线的变化不表达质量好坏。

| AQI 等级 | 优 · 1 | 良 · 2 | 轻度污染 · 3 | 中度污染 · 4 | 重度污染 · 5 | 严重污染 · 6 |
|---|---|---|---|---|---|---|
| 已核版本图例参考色（V3.0 §8.2 的 2026 推荐色） | `#00E400` | `#FFFF00` | `#FF7E00` | `#FF0000` | `#99004C` | `#7E0023` |
| 标签字 / 浅底（首页实测） | `#196042 / #d7eddf` | `#6b521e / #f3eaca` | `#81461e / #fae2c8` | `#943b40 / #f6dcdc` | `#79264f / #edd9e5` | `#6a293c / #e9d3da` |

在图例、点位及等级分布中使用带等级名称、与标准一致的色标，浅色标签附等级文字。亮色点在浅底加深轮廓（候选 `#405f75`、1–2px），例如黄点的填色须保持标准黄，轮廓与邻近地图底色达到适用的非文本对比。图例可读到等级、区间和系列。2012 系列的一级从 0 开始，2026 系列从 1 开始且定义域至 500。按后端已确认的系列和等级映射，不在浏览器用阈值重分级。标准未知时使用中性标记，保留获准的源描述，退出要求已知标准的排名。2026 系列出现 0 或大于 500 时保留源值及待核状态。真实浓度零值 `0`、缺测和删失分别呈现，观测是否有效取决于服务端质量状态。

| 材质 | 填充、滤镜与边缘 | 使用位置与边界 | 实体回退 |
|---|---|---|---|
| `atmosphere` 氛围 | 实测 123° 天空底色，左上 `#f2fcff`、右上 `#93c8eb` 两个径向亮区。无滤镜、边框或投影。 | 应用画布。保持静止。装饰不能接收指针或妨碍地图释读。 | `#d0e6f4` |

| `content` 内容表面 | 常规实测 `112deg, #f5fafff2 → #e7f2faf0`，KPI `108deg, #f6fbffdc → #e8f3fbe3`。1px `rgb(96 139 168 / 27%)` 边，轻影 `panel`，背景模糊 0。 | 指标与图表仍有云白层次。地图底 `#f1f9fc → #dfedf5`、长表 `#f5faff → #eaf3fa` 更稳。数据行、文字及绘图区不叠玻璃。 | `#eff6fb`，表头保留 `#dceaf5` |
| `elevated` 临时玻璃 | 首页菜单、抽屉和对话框实测 `rgb(242 250 255 / 65%)`，叠 135° 边缘亮层 `#ffffff40 → transparent 48% → #b7dbf429`，滤镜、边和浮影同功能层。**候选**长菜单、日期网格或长文抽屉用同底 82–94% 或实体，仍保留上沿高光。 | 紧邻触发器的临时阅读/操作面。一个活跃浮层内只由外壳模糊。短文本 Tooltip 可用实体底色 `#21465e` 配白字。复杂编辑进入抽屉或独立页。 | `#eff7fc`，文本提示 `#21465e` |

- `panel`（实测）采用 `inset 0 1px #ffffffc9, inset 0 -1px #c3d9e62e, 0 2px 4px -3px #35618040`。`float`（实测）采用 `inset 0 1px 1px #ffffffed, inset 0 0 0 1px #ffffff63, 0 3px 9px -5px #23486365, 0 14px 36px -16px #193f5f70`。内缘表现受光，外影表示与背景的距离。按压可以收轻外影，面板本身保持静止。
- `scrim` 实测 `rgb(22 54 80 / 24%)`。正式默认用纯色遮罩，浮层自身负责分离，原型额外的整屏 2px 模糊留作性能对照。透明度只用于背景层，文字、数值和图标保持完整。不要给玻璃的祖先做整层透明度动画而意外改变其取景范围。
- 圆角按容器包围关系分配。首页字段 9px、工具 10px、菜单 12px、面板 16px、侧栏及对话框 20px。候选统一为 `control 8–10`、`nested 6`、`menu 12`、`panel 16`、`sheet 20`、`capsule 999`。内外等距时用「外半径减内距」作光学起点。胶囊留给连续分段、短身份标记和紧凑导航。
- `z-index` **候选**。画布 0、局部图面/提示 1–4、粘性列/表头 5–10、应用导航与固定工具栏 20–30。应用浮层统一接入 Element Plus 的一个叠放管理器（起始 2000）。菜单、遮罩与 Dialog、其内部 Select 按打开顺序递增。子菜单必须在所属 Dialog 之上，背景提示必须在遮罩之下。焦点跳转链接只有在所属层可用时浮至顶端。Toast 在当前活动层的反馈区呈现，不抢焦点或穿透遮罩。不要用一个任意大的 `z-index` 修复裁剪或错误的挂载点。
- 先让实体主题独立可用，再以 `@supports` 增强。`prefers-reduced-transparency: reduce`、显式实体模式或已测低性能配置均应关闭滤镜和透明装饰，**包括内容卡与 KPI**。在偏好查询不可用但支持滤镜的浏览器，仍能通过项目外观设置或本地交付配置启用实体表面。高对比/`forced-colors` 用系统色、实边和真实焦点，选中不能靠阴影。图表另有文字/数据表。分别实测偏好分支和无滤镜分支。[MDN 背景滤镜](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter) · [降低透明度](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-transparency)

## 4. 排版、图标与布局

中文正文优先本地、有许可的 Noto Sans SC，拉丁字母和数字用本地 Inter。原型栈先 Inter（限拉丁字形）、再 Noto Sans SC、`PingFang SC`、`Microsoft YaHei`、`Noto Sans CJK SC` 与 `sans-serif`。系统已安装字体只作回退，新增分发资源需核许可和署名。图标沿用 `@element-plus/icons-vue` 的轮廓、笔重与视觉大小，品牌标志单列。

## 5. 组件与状态

**先看动作语义，再选择外壳。** 立即操作用按钮，去另一个资源用链接，一组互斥视图用分段，需要保存的条件用表单。原型的日期胶囊是静态时间标签，正式日期选择器必须有独立可辨的触发器。

| 状态 | 可见反馈及行为 |
|---|---|
| Default / Hover | 默认已有边界或动作标签。精细指针悬停改变底色、文字或轻微边缘高光，移开收回。触屏不依赖悬停。 |
| Pressed / Focus visible | 按下立即压低高光或内收 1px，释放可取消。键盘焦点用不改变尺寸的环，鼠标移开也保持键盘焦点。 |
| Selected / Expanded | 选中用勾、当前项标记或选中线配底色。展开用方向、`aria-expanded` 和受控面板关系。可同时看出哪项选中、哪项有焦点。 |
| Disabled / Read-only | 禁用动作给出原因或替代入口，原因在禁用控件之外也可读。只读值保留正常对比、标签和复制能力，移除编辑按钮和输入态边框。 |
| Loading / Error | 请求开始立即确认，按钮保留宽度、状态文字，拦重复提交。失败保留非敏感草稿，字段内说明原因和修复方法。提交后聚焦首个出错字段或错误摘要。 |

## 6. 筛选、选择与动效

- 页面区分编辑条件和已应用条件。搜索等轻量操作可即改即查。跨对象、时间窗、指标与方法组成的分析用「应用」，使结果旁始终能读到其条件、锚点和输入版本。条件改变重置相应游标。返回恢复合法的筛选、滚动和对象。请求可取消，迟到的响应需与当前查询和会话身份匹配才可显示。
- **环境与数据发现。** 默认进入正式数据域。有权查询但结果为空时显示空态，当前用途被拒时说明限制。用户主动进入 F 合成演示后，工作区和下钻页持续显示「合成演示」。切换环境或不兼容产品时清除旧观测、无效选择和游标，使在途旧响应失效。发现数据从获权对象与产品出发，按兼容指标和有证据的可用时间引导查询。目录只给出一个观测锚点时，可从该时刻进入。其余日期覆盖标为未知，允许按契约选窗查询，仅凭明确依据标记可用或禁用日期。
- **全国总览共用一个选中城市。** 地图、榜单、表格、详情和允许写入 URL 的导航状态都取同一稳定城市 ID，读数另绑定当前数据域、产品和快照。名称仅作展示，站点下钻还要核站址期。URL 仅保存可分享的非敏感导航状态。首次进入先核 URL 对象的权限与已应用条件，缺少有效选择时才用默认对象。从任一入口选城，同时更新详情目标及可见行、点的选中标记。悬停只预览，键盘焦点独立。无坐标时标「仅列表可用」。
- **何时保留选择。** 翻页暂时看不到所选城市时保留有效选择，不往本页补行。改排序、切显示指标、刷新同一窗口也保留仍有效的选择。地图复位只改变视野。已应用筛选确实排除该城时，提示「所选城市已不符合当前条件」，再清除选择或显式改选符合条件的城市。撤权时撤下受限选择、读数和详情，清理相关缓存及 URL 状态，取消在途请求并丢弃迟到响应。
- 图表点击、键盘下钻、可搜索列表和详情遵循同一口径。图例、定位、复位和选择各用明确的动词。高影响任务确认时展示对象、作用范围、版本和结果入口，先反馈已受理，再依运行账本更新结果。

**已定待实现。** 微交互与动效是体验质量的验收项。主要控件的按压、选中、展开和释放应有自然、及时且可中断的反馈。密集图可以关闭数据插值，仍须保留适用的选中、定位、图例和提示反馈。

| Motion Token（候选默认） | 时间与缓动 | 用途和反馈 |
|---|---|---|
| `press` / `hover` | 90ms `ease-out` / 140ms `ease-out`（后者首页实测） | 压下高光内收，释放复原。精细指针改变浅底，键盘焦点环立即出现。 |
| `menu-in` / `menu-out` | 180ms `cubic-bezier(.2,.8,.2,1)` / 120ms `cubic-bezier(.4,0,1,1)` | 从触发边缘显现，最多平移 4px，关闭回到触发方向。Tooltip 的触发延迟与动画时长分别管理。 |

动效在现有技术栈内完成，使用 Vue Transition、显式 CSS transition 属性和 ECharts 更新配置。主要移动/淡变用 `transform`、`opacity`，玻璃边缘反馈可用静态高光层改变强度。快速开关从当前位置反向或取消，状态提交和下一次输入不等动画结束。固定大背景、长表和大量地图点避免持续滤镜、逐个进场及反复布局。减少动效时取消位移、缩放、平滑滚动和图表插值，保留文字、选中环与即时反馈。遇到卡顿，在实际滚动、缩放或开关浮层时测量，针对造成延迟的效果降级，保留其余反馈。[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) · [Fluent Motion](https://fluent2.microsoft.design/motion) · [Web 动画性能](https://web.dev/articles/animations-guide)

## 8. 页面模式与业务状态

**已确认的导航。** 用户工作区设「监测总览、分析工作台、数据查询、我的空间」，城市与站点各有独立详情页。管理员登录后也默认进入用户工作区。管理入口依赖服务端对当前会话给出的真实角色或能力，只提供有权使用的「采集任务、数据质量、系统运行」及返回用户区的切换。现有 `/me/` 只返回个人资料，正式管理导航需要补足这一投影。模块职责已确定，首页以外的具体构图均为候选。

| 采集任务（M08） | 计划/任务（Job）→ 业务窗口及各次 Run → 子项、批次、缺口与异常 | 分开显示投递、运行结果及窗口覆盖。手动触发、暂停/恢复或重投按获准动作执行，凭回执定位原运行与关联质量事件。 |
| 数据质量（M09） | 质量事件 → 受影响的对象、字段与窗口 → 观测证据、可信版本及争议 → 受控处置 | 并列显示当前修订和相关证据，争议值标为待核。按权限、版本和理由执行服务端允许的裁决，显示回执与影响范围。官方观测的更正走修订流程。 |
| 系统运行（M10） | 服务健康 → 来源与产品状态 → 有界运行趋势 → 获权诊断入口 | 分列 Web、数据库、Redis、Worker、Beat 的健康证据。来源异常定位到相应产品与窗口，诊断从获权账本进入。缺少或过期的证据标「未知」。 |
| 公共访问区 | 平台说明、数据来源与使用说明 → 登录 / 注册 | 说明访问条件、数据出处和允许用途。身份页沿用晴空材质与窄表单，支持密码管理器、粘贴、键盘提交。注册后引导登录。 |

**管理边界。** Vue 管理工作台沿用晴空玻璃，也可用更紧凑、稳定的表面核对长账本。S07 已提供获权的账本查询、质量处置、健康与趋势等接口。原 P0 中来源/产品配置、周期任务的创建与编辑仍有管理入口缺口，须核定配置方式及所需接口。Django Admin 承担账号与低风险基础字典职责，目前可核实的是受控账号管理。历史导入暂存注册、备份签认、备份清理和实际恢复按受控主机流程执行，网页仅呈现契约开放的状态、动作或意图。[v1 管理与主机分工](../docs/api/v1.md#管理员的-f-请求)

**全国计数与分母。** `summary.state=unavailable` 时显示「当前不可提供汇总」。`state=ok` 时，等级分布按每个已核标准分别展示，以该组 `ranked_city_count` 为分母，分子取组内 `distribution` 的等级计数。`summary_eligible_city_count` 只标「获准汇总城市数」。覆盖摘要配对 `covered_city_count` 与 `expected`，分别表示当前查询的覆盖数和应到数。前者为 `null` 时写「覆盖数不可完整提供」，后者为 `null` 时写「应到未知」。已知零显示 `0`，分母为零或未知时只列可披露计数。汇总权限和分组分母以服务端结果为准。[全国汇总字段与投影](../backend/observations/s04_national.py)

## 9. 响应式、可访问性与验收

| 验证视口 | 对应的布局行为 |
|---|---|
| 1920×1080、1440×900、1280×800 | 桌面侧栏可收展，标题、图表、表格保持网格边缘。原型 ≥1650px 放大部分字级。1051–1250px 收紧间距。宽度阈值由标题、图例、筛选和数值拥挤点决定。折叠/展开均要抽查。 |
| 768×1024 左右 | 原型 ≤1050px 转抽屉，地图/榜单两列，分布与提示进入下一行。641–810px 下排两列、覆盖跨行。正式页可让条件栏变摘要/抽屉，保持已应用条件和结果可见。 |
| 390×844、320 CSS px | 原型 ≤640px 主区单列、KPI 首行两项、次行三项、筛选分行，≤379px 再排筛选。窄屏正式页面按阅读顺序排。图例区间可通过可见说明按钮读取，来源、时区、单位、质量和覆盖有可达位置。表格/地图允许局部二维滚动，关键对象列和详情操作可到达。长菜单翻转或用抽屉，考虑安全边距与软键盘。 |

适用 WCAG 2.2 AA 条款作为验收基线。普通文字对比 ≥4.5∶1，大字（常规 ≥18pt，粗体 ≥14pt，约 24/18.7 CSS px）≥3∶1。识别控件状态及理解图形所需的非文本线索按适用条件 ≥3∶1。实际截图在最亮、最暗及滚动到图表背后的合成背景取样，覆盖选中、键盘焦点和浮层。目标 ≥24×24 CSS px 或满足 2.5.8 的间距/等价入口等例外。触屏主要操作优先 44×44。焦点按阅读顺序可见且不被粘性栏/浮层完全盖住，弹层打开和关闭保持合理顺序。可放大文字至 200%，在 1280px 宽浏览器以 400% 缩放等效测试 320 CSS px 重排。以键盘及单点操作完成核心流程。[WCAG 2.2](https://www.w3.org/TR/WCAG22/)

**设计验收按变更选场景。**

1. 记录路由、数据类型和版本，在桌面、窄屏、必要的真实浏览器缩放下截取同一状态。改动已有页面留前后对照。核边缘、标题/数字基线、裁切、整体横溢与局部滚动。
2. 实际用鼠标、触屏或触摸模拟、键盘走受影响的操作。查默认/展开/焦点/选中、快速切换、返回，以及关闭浮层后焦点的位置。选城回归至少覆盖「点 A → hover B → 切指标 → 榜单选 C → 表选 D → 复位视野/返回」，逐步核对 ID、点/行状态和详情。另验翻页保留、筛选排除后的提示，以及切域或撤权后的旧响应无法回显。
3. 在明暗背景、实体模式、减少动效及适用的高对比下检查展开后的真实 DOM、可读性与替代入口。用含长中文、缺口、零、未知标准、权限拒绝、版本变化和慢响应的合法样本检查受影响状态。
4. 观察控制台、越界网络、滚动/缩放掉帧、浮层反复开关和图表实例回收。必要时用性能时间线分别记录接口等待、渲染和交互。跨引擎影响大的材质、定位和焦点改动在 Chromium、Firefox、WebKit/Safari 可用环境复核，触屏模拟与真机分开报告。
5. 记录 `PASS / FAIL / NOT RUN`、复现步骤和未覆盖范围。自动检查、浏览器人工核查及真实会话联调各有自己的记录。正式地图与在线运行分别按项目验收条件取证。

## 10. 维护约定

正式前端建立主题时，**数值在一份共享主题中实现一次**。CSS、Element Plus 和 ECharts 通过语义角色引用同一来源。本文维护设计意图、角色映射、适用范围及验收例。开发者按 §9 验证候选值与局部调整，落地时在同一补丁记录取舍、主题文件或符号及实测范围。新增公共组件先复用已有变体，跨页面的新角色在本文补其用途、状态、回退和验证样例。涉及文首所列实质性变更时交用户决策，业务语义或冻结契约的变化遵循项目变更审查。

### 正式工程实测 · S08

共享色义与材质位于 `src/styles/theme.css`。`src/App.vue` 监听减少透明度、减少动效、强制颜色及用户的实体主题选择，通过 `data-material` 同时更新顶栏、侧栏、数据卡与地图占位。桌面侧栏收起为 64 CSS px。窄屏菜单打开后，主内容进入 `inert` 状态，Esc 关闭菜单并归还焦点。

在同源生产构建与合成 F 数据上，Chromium 实测减少透明度时的五个表面均使用实体填充。六种视口的导航、窄屏键盘操作、抽屉、模拟触摸和实体主题刷新复访见 S08 验收矩阵 B16。三处 axe 扫描已完成，玻璃合成背景的对比度另需逐状态取样。跨引擎、物理设备及辅助技术的覆盖范围按矩阵记录。[S08 验收矩阵](../docs/verification/S08.md)
