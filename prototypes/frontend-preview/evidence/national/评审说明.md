# 全国空气质量总览原型

在 `prototypes/frontend-preview/` 使用本轮验证的 Node 24.19.0 与 npm 12.0.2 执行 `npm ci`、`npm run dev`，浏览器打开 `http://127.0.0.1:4174/`。用 `npm run build` 生成静态包。浏览器测试默认查找本机 `/usr/bin/google-chrome`，可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定可用的 Chromium 系浏览器。两者皆无时先运行 `npx playwright install chromium`。随后用 `npm run test:browser` 验证生产预览。[浏览器配置](../../playwright.config.ts)

此目录保留已获认可的 F 全国总览。`overview-full.png` 是 1448×1086 视口的原全页截图，`desktop-1440.png` 是 1440×900 首屏，`mobile-390.png` 是原窄屏全页。

## 视觉与交互

沿用参考图的侧栏、五项摘要、左大图中排行右分布、三块次级统计与通栏列表。Apple 的材质分层用于侧栏、控件和地图浮层，图表和表格保留较实的阅读表面。监控仪表盘的紧凑排行和共享对齐线用于城市列表。主要对照资料包括 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)、[Vercel Observability](https://vercel.com/docs/observability) 和 [Datadog Dashboards](https://docs.datadoghq.com/dashboards/)。

第一次实拍后放大地图及城市标签，增强玻璃边缘，修复窄屏溢出。独立审查后扩大了等级筛选触控区，保留按钮可见文字作为无障碍名称，补齐 O₃ 缺测图例，并为地图提示文字留出宽度。

## 数据与地图依据

F 合成快照模拟 L 产品的同刻城市列表。50 城合成名录中有 47 城到报，46 城有地理点位。趋势为合成台账每小时到报城市数。各污染物使用等级。云汀市只在列表和同刻详情中出现。原同城 C 产品详情与其他原型路由已清退，原跨页按钮保留位置并提示演示范围。顶部原「治理账号」保留作为静态 F 演示标签。正式地图仍待地理材料、点位证据和验收。[当前工程验收](../../../../docs/verification/S08.md)

地形源自 Natural Earth 1:50m 阴影地形。城市标记使用 Natural Earth 城市中心点，`sample-cities.json` 保留原始经纬度和 `neId`。底图与点位使用相同投影。使用依据见 [Natural Earth terms of use](https://www.naturalearthdata.com/about/terms-of-use/) 与[原始地理数据](https://github.com/nvkelso/natural-earth-vector)。

- **PASS** 独立 `npm ci --offline`、TypeScript、ESLint、3 项 Vitest、生产构建和 Vite 开发启动。依赖锁装入 210 个包，沿用 `package-lock.json` 的保留依赖版本。
- **PASS** Chrome 158.0.8127.36 共 21 项浏览器用例，覆盖 8 档视口、地图与选中、榜、图表、表格、筛选、分页、短详情、键盘及演示边界。1440×900 与 390×844 的 axe 扫描无自动违规。运行守卫未见外网、API 请求、失败资源或运行错误。[浏览器用例](../../e2e/national.spec.ts)
- **PASS** 同一 Chrome 对 `b12f33f7` 与清退后版本复测。1440×900、1448×1086、390×844、320×720 的首页全页 PNG、布局、文本和画布尺寸逐项相同。生产与开发模式各自对照，本地收据在 `tmp/s08-retirement-pk99LJ/{before,after,before-dev,dev}/capture.json`。
- **NOT RUN** 本轮未覆盖其他浏览器引擎、物理设备、实际读屏与视觉性能。构建仍有大于 500 kB 的分块提示。
