# 全国空气质量总览原型

在 `prototypes/frontend-preview/` 运行 `npm run dev`，浏览器打开 `http://127.0.0.1:4174/`。本目录的截图来自实际浏览器。`overview-full.png` 是 1448×1086 视口的全页截图，`desktop-1440.png` 是 1440×900 首屏，`mobile-390.png` 是窄屏全页。

## 视觉与交互

沿用参考图的侧栏、五项摘要、左大图中排行右分布、三块次级统计与通栏列表。Apple 的材质分层用于侧栏、控件和地图浮层，图表和表格保留较实的阅读表面。监控仪表盘的紧凑排行和共享对齐线用于城市列表。主要对照资料包括 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)、[Vercel Observability](https://vercel.com/docs/observability) 和 [Datadog Dashboards](https://docs.datadoghq.com/dashboards/)。

第一次实拍后放大地图及城市标签，增强玻璃边缘，修复窄屏溢出。独立审查后扩大了等级筛选触控区，保留按钮可见文字作为无障碍名称，补齐 O₃ 缺测图例，并为地图提示文字留出宽度。

## 数据与地图依据

F 合成快照模拟 L 产品的同刻城市列表。50 城合成名录中有 47 城到报，46 城有地理点位。趋势为合成台账每小时到报城市数。各污染物使用等级。云汀市只在列表中出现，可进入已有的同城 C 产品详情。正式后端、在线数据与正式地图验收不在本轮范围。

地形源自 Natural Earth 1:50m 阴影地形。城市标记使用 Natural Earth 城市中心点，`sample-cities.json` 保留原始经纬度和 `neId`。底图与点位使用相同投影。使用依据见 [Natural Earth terms of use](https://www.naturalearthdata.com/about/terms-of-use/) 与[原始地理数据](https://github.com/nvkelso/natural-earth-vector)。

## 验证

- PASS · 生产构建、TypeScript、变更文件 ESLint、18 个单元测试和 17 个 Chromium 浏览器测试。
- PASS · 实测 1448×1086、1440×900、1920×1080、1280×800、768×1024、390×844、320×720。覆盖地图、图表提示、排序、搜索、组合筛选、分页、下钻和工作区权限。1440px 与 390px 的 axe 扫描通过。
- FAIL · 全原型 ESLint 留有既有 `src/city/CityPage.vue:46` 的全角空格。构建通过并提示共享图表分块超过 500 kB。
- NOT RUN · Safari、Firefox 和移动真机性能测试。

本轮采用 `frontend-delivery`、`taste-skill`、`ui-ux-pro-max`、`web-design-guidelines` 和 Playwright。`impeccable` 使用本地视觉打磨指引，命令行启动器缺少执行权限。
