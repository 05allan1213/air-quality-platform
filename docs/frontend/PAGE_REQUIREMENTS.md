# Phase 02 页面需求与验收基线

本文件规定页面职责、既有业务要求和可执行的验收预期。当前实现、待后端核验及待产品确认的事项在对应页面注明。以仓库 [DESIGN.md](../DESIGN.md) 为唯一视觉和交互呈现基准，以 [业务规则](BUSINESS_RULES.md) 为数据口径和授权依据。页面入口、实际调用及冲突分别见 [路由](ROUTES.md)、[API 映射](PAGE_API_MAPPING.md) 和 [审计报告](BASELINE_REVIEW.md)。

## 共用业务和设计验收

- 首载、局部加载、成功、无匹配/无观测、部分结果、缺测/删失、陈旧/未知、拒绝、服务错误各有适用的反馈。仅在仍获权且口径相同时可保留前次结果，并标时标与刷新状态。应用新条件后清不适用结果及游标。换会话、数据域、用途或撤权取消在途读取并丢弃迟到响应。无总数、版本、坐标、分母或证据时保留未知。
- F 的标识伴随页面、派生数据和下载。正式模式按现行授权链接、返回等级、字段、统计、分母和名次显示。数值零、缺测、删失、未知系列分别表达。观测、发布、抓取、执行、首次有效写入时间各有依据。研究的有效性阈值、分箱与统计以服务端返回的口径和结论为准。
- 页面沿用 DESIGN 的晴空浅色、共享 token、字阶、材质和层级。正常模式保护已确认的层次、光学细节与反馈。功能玻璃限规定外壳，长表、数据行和图面使用稳定底。SYS-403/404 单层滤镜、分析与采集的主表居中、按语义区分的日期输入、短颜色过渡及密码区折叠按 S08-02 至 S08-05 的确认范围验收。交互状态有颜色外线索，键盘及触屏可完成等价任务，图表有文字或表格，浮层按层 Esc 和归还焦点。验收涵盖实体回退、减少动效/透明度、强制颜色、合成对比、命中区及宽窄与断点两侧。
- 受控操作显示对象、范围、版本、理由、提交状态和下一步。安全读取可重试。写入不确定按原请求或回执核实。受理、已投递、已执行和业务结果分别展示。
- 初始优先级保留 P0 各核心页面及主要链路，P1 为下文治理、分析和投影覆盖，P2 是历史地图回放、进阶个人排序/通知、气象变量等可选范围。阶段性未接入项留在所属页面，新增契约、业务范围或设计决策需按所属规则确认。

## PUB-01 平台说明

**需求与当前操作**　说明观测、查询研究和治理三类用途，解释公开访问与授权工作区，链接数据来源、登录、注册和工作区入口。静态说明读取本地内容。F 可进入合成工作区，真实入口引导登录。

**验收**　游客可浏览并使用宽窄导航，在明确数据性质和实际访问条件后进入下一步。品牌标题、功能概述和访问说明的顺序符合 DESIGN。入口在返回和键盘导航中可达。 [实现](../src/public/AboutPage.vue)

## PUB-02 数据来源与使用边界

**需求与当前操作**　说明 F/L/C/T/D/S/H 的内容、来源、时点或时段和用途限制。区分数据、地图和软件依据，以仓库登记/来源材料为准。页面静态内容不能裁决当前产品权限。目录支持按组和产品定位、显示当前位置，移动可展开相应卡并聚焦目标标题。按安全来源返回，亦可去公开说明或身份页。

**验收**　逐产品核口径、使用边界、导航及标题焦点。L 的卡片现写「公开」「城市与行政区划」，与同页详情和获权快照规则有差异。可展示范围和许可说明待确认（B07）。素材和软件依据仍以项目登记为准，页面覆盖待核。 [实现](../src/public/SourcesPage.vue) · [来源内容](../src/public/sourceCatalog.ts) · [素材登记](ASSET_RIGHTS.md)

## AUTH-01 登录

**需求与当前操作**　用户名、密码可输入、粘贴、显隐并用键盘提交。校验、提交中、凭据错误、限流、过期、CSRF 及系统错误有可读反馈。登录成功轮换 CSRF，复核资料和能力，再回安全站内目标或用户总览。仅有管理能力的账号按目标授权分流。网络不确定先核会话。支持去注册、公共说明。

**验收**　真实会话证明普通账号默认去 M01，允许的安全回跳重新核权，外站和无权目标无私有显示。仅管理账号的质量、运行登录回跳差异见 B04。复测回车、密码管理器、焦点、限流与会话轮换。 [实现](../src/auth/AuthFormCard.vue)

## AUTH-02 注册

**需求与当前操作**　填写用户名和密码，校验用户名字符及长度和至少 8 位的密码。重复提交锁定，字段、通用注册失败、频控、结果不确定及成功有反馈。注册创建普通用户，成功页可去登录并有 5 秒定时跳转，沿安全 `next`。权限由后端授予。

**验收**　有效注册、弱密码、重复名、格式错误、频控、响应丢失分别演练，回登录后仍需身份验证。F 重名可归字段，历史正式响应仅通用 400，按真实响应展示。 [实现](../src/auth/AuthPage.vue) · [表单](../src/auth/AuthFormCard.vue)

## M01 监测总览

**需求**　同一 L 快照展示时刻、来源与覆盖。S09-01 以可搜索、可按获权链接下钻的同刻列表作基本路径，支持的摘要、榜单和分母随正式投影呈现。正式地图和全国趋势分别验收。F 成功态按 S08-01 保留「优良城市」「污染城市」「样本到报率」三项摘要和完整地图、榜单、分布与城市表。应用合规筛选、排序、游标，当前可用的地图/榜单/表格/详情之间按稳定 ID 选城。按服务端的分组分母、排名和并列呈现，未披露计数维持未知。

**当前**　F 演示提供摘要、地图换指标、焦点/缩放复位、榜单高低切换、分布、提示、趋势和覆盖、城市搜索/地域/等级/排序/本地页、短详情。合成浓度/IAQI、应到/缺报名称、首污构成及趋势有独立 F 口径。实际正式模式为精简的同刻城市、标准、AQI、质量列表、获权链接和重读，地图固定不可用，后续游标只提示。

**验收**　同快照、部分汇总、未知标准、无点位/空/拒绝/错误均清晰。筛选改变回首批，翻页/换指标保留合法选择，复位只改变地图视野，返回恢复获权上下文。F 三项摘要在 390/320 CSS px 默认字号同排，文字放大时可重排。真实同刻列表的检索仍缺，侧栏、翻页及支持投影的呈现存在前端差距。地图和正式浓度/趋势投影另核 B01–B02。 [正式分支](../src/national/NationalPage.vue) · [F 分支](../src/national/DemoOverview.vue)

## M02 城市详情

**需求与当前操作**　C 城市主 AQI 和六污染物浓度、质量及独立观测时间为主体。观测条件弹窗分别编辑 C、T、S 的产品、锚点、标准和适用窗口再应用。T 独立最近 24 小时趋势，有报表和逐槽读数。C 小时历史显示自己的半开窗、报告窗、时区和结果，可进入 M06。D 单独按源地方日期与正式口径展现，当前显示「暂未开放」。S 目录按获权链接及站址期分页，可进 M03，F 另有站名/类型筛选及最近 AQI、首污和总数。可关注当前对象，进入研究预填，返回安全来源。

**验收**　C、T、S 的读取/失败/缺测可分区，L/C/T 同时刻也保留各自依据，站点数值不代替 C，C/T 不代替 D。核 C 七槽、T 缺口、站址期游标、切换清理、日报入口和 M06 回跳。纯城市深链在仅有 S 权时的发现、正式目录字段及 D 来源见 B08。 [实现](../src/city/CityPage.vue) · [读模型](../src/city/useCityDetail.ts)

## M03 站点详情

**需求与当前操作**　显示稳定站身份、产品、获权站址期、有效期、来源、城市和可披露的坐标/时效。多站址选期并清上期内容。最新卡和最近记录按 DESIGN 显示六项污染物的逐值时间、单位、质量及陈旧。获权 AQI 可在历史或趋势选择。趋势可切指标/窗口，保留缺槽，提供数据表。可关注稳定站而非同名站，携获权站址期进入历史、普通查询或比较。

**验收**　核多站址、身份复用/迁址、缺坐标、断源、旧值与精确空窗，最近值不回填到显式空槽。逐项时间、有效零、缺测、删失及报告窗准确，离开后不回显失权数据。最近记录按 S08-03 通用列职责验收。真实多站址、H 许可与时间字段待核，覆盖日历及额外异常/迁址投影保留在 B09。 [实现](../src/station/StationPage.vue) · [趋势](../src/station/StationTrendPanel.vue)

## M04 分析工作台 · 对象对比

**需求与当前操作**　按已获权系列选同层 2–5 个对象和单指标。支持同口径 C 多城、同城兼容 S 多站、同一获准 H 数据集且已核同城的不同站。编辑对象、时窗、指标、单位、标准、窗口和粒度后应用。显示对齐曲线、各列覆盖、共同应有/有效样本、差值和变幅、获权排行或局部结论，进入 M06 支撑明细，保存方案与受控导出。当前展示覆盖、曲线及适用的双对象差值派生读数，未渲染专用排行与部分覆盖子窗。

**验收**　逐对象 18/24、共用 12/24 的样本仅给允许的曲线与证据及不足原因。基准零时变幅留空。失败、许可撤回、范围和版本变化不能复用旧明细或下载。正式排行、部分覆盖投影及当期 H 样本见 B10。 [条件和限制](../src/analysis/conditions.ts) · [结果](../src/analysis/AnalysisResults.vue)

## M05 分析工作台 · 趋势与分布、指标关联

**需求与当前操作**　趋势与分布选单对象单指标，按小时、日、月、季显示获准时序和统计。图表、数据表、分布、四分位和日内热图随投影开启，可下钻支撑。指标关联选同对象两项不同浓度，显示共同样本、散点、Pearson、覆盖及限制，结论只描述关联。工作台三模式分别保存已应用条件，提供更新/保存方案、整组明细或汇总票据。当前未见独立箱线图、异常候选处置或完整月份/站址/系列分段的呈现。

**验收**　模式切换与回图恢复，图表标明产品、窗口、单位、时区、方法和样本，缺口、未知分母、覆盖不足、常数列和 P<30 仅显示服务端获准解释。图表/明细/票据绑定同一父输入版本。无图形投影给局部反馈。月季、异常与箱线投影及布局保留在 B10。 [分析工作台](../src/analysis/AnalysisPage.vue) · [结果](../src/analysis/AnalysisResults.vue)

## M06 数据查询

**需求与当前操作**　从获权目录选产品、对象、指标及精度口径。自由查询分窗口和最近有效。精确读选一个对象、指标与标准，以观测时刻或 D 地方日报日定位。支持应用/清空、游标批次、选择记录和证据区。时间窗口半开，最近有效固定 valid。记录以获权投影显示时刻、角色、单位、值、质量、来源、署名及修订/版本，抓取时刻无据则未知。研究明细模式依据父查询、支撑类型/时间桶和对应版本复现，关闭可回原分析。

**验收**　首载、空目录、无匹配/无观测、字段裁剪、用途拒绝、网络错误、游标 409 和父版本失效均按相应范围处理。导出先确认整组范围、来源、质量口径和列，目前窗口条件满足时可申请并到 M07 下载，研究整组可由分析页申请。当前默认列和确认文案存在 B11 所列差异，任意质量子集、单桶、最近有效和精确单键不能直接等价导出。导出需独立许可与版本，真实列选择和 D 披露待核。 [查询](../src/query/QueryPage.vue) · [研究支撑](../src/query/ResearchSupportPage.vue)

## M06 观测历史

**需求与当前操作**　从 M02/M03 进入单城市或单站址期历史，显示来源、窗口和获准数据，可经当前条件跳普通查询或返回详情。站址期多指标按同一观测时刻合页，获权 AQI 优先、六项按 M03 顺序。先按 UTC+8 选日期，再选该日任意小时或全部时刻，换日清小时。实际分钟落入小时窗口，按实测时刻倒序逐页浏览。

**验收**　核跨游标同一时刻的记录合并、日期与小时的地址恢复、日历最近有数月份和空时刻、换日、迟到响应。可读错误与空结果保留合法条件。视觉与减少动效遵循 DESIGN 对此视图的具体要求。 [实现](../src/city/RelatedObservations.vue)

## M07 我的空间与共享账号设置

**需求与当前操作**　默认资源概览，各模块独立加载和重试。关注可按当批检索、筛选、排序、选择首选产品/站址或移除，复访前确认目标可见。方案可改名、删、复跑、编辑。编辑由分析工作台更新父意图及修订。近期导出按票据状态和日期复访、下载或移除，已过期回申请来源。当前批的操作范围清楚，确认首批完整才给总数。资源按当前会话隔离，快照或下载源缺失保留保守入口。

**共享账号设置**　应用壳的顶栏、M07 身份摘要共用面板。展示本人资料和工作区，编辑姓/名、检查未修改输入、展开新旧密码/确认、退出。关闭或退出遇未保存内容需确认。提交中锁定重复动作，成功保持一致会话或改密后重登，失败在相应区域反馈。保留短屏正文滚动及焦点回归。

**验收**　核独立加载/空/失败、资源撤权、排序与数量、稳定身份、同名/迁址、改名冲突、方案方法变化、票据过期及本人下载。以两独立会话验证跨人 404、不复现旧数据。目标收藏直查和票据来源投影待核 B12。 [个人空间](../src/personal/PersonalPage.vue) · [账号面板](../src/auth/AccountSettings.vue)

## M08 采集任务

**需求与当前操作**　四账本按能力呈现 Job、Window、Run、历史导入。应用产品与窗口，浏览游标，在抽屉查看 Run/Window、到报/缺项、批次、审计、质量和写入证据关联。模板草案、提议、分界、激活与放弃按获权模板和版本执行。Job/产品/来源控制、手动运行、重投按自身授权和可用状态办理。独立创建 Job 和首挂计划当前仅 F 可演练。历史导入以获准暂存 ID 受理并在账本读进度。

**验收**　S09-02 从已有获权 Job 或登记模板草案开始验证。独立建 Job 和首挂计划保留缺口，按已定范围单列。待投递、配额等待、完成、无新、部分、重复、缺口分别表达，同窗调度、手动与重投关联清楚。不可补或无权时解释获准理由。写入不确定保留原信封或尝试 ID，可靠回执后再读。核暂停/恢复、跨分界、审阅裁剪、原回执、错误或空态及深链异常 B05、B13。 [工作台](../src/collection/CollectionPage.vue) · [动作处理](../src/collection/useCollectionCommand.ts)

## M09 数据质量

**需求与当前操作**　按获权产品、Run/Window、状态进队列，打开事件及当前/候选修订、字段差异和按需证据。桌面队列与详情并排，窄屏两视图。按事件版本和证据做认领和有据更正，提交后查看回执和影响，必要时再读对象。保留隔离、结案、站址变更、许可撤回/处置仍属原有治理要求或外部交接，当前 SPA 缺相应入口/资格投影。批量复核为历史增强待确定。

**验收**　结构漂移只展示获准定位，事件 403/404 不暴露存在性。版本变化回预览，失权收回证据和动作。普通结案不得替代更正或解除争议。以更正回执验证受影响组与无关组、再查询和旧票据状态。真实当前动作资格与正式源证据见 B14。 [质量页](../src/quality/QualityPage.vue) · [裁决模型](../src/quality/qualityModel.ts)

## M10 系统运行

**需求与当前操作**　Web、PG、Redis、Worker、Beat 探测与队列就绪分开。按获权产品/窗口看当前来源与运行证据，诊断条件应用后读取有界源地方日趋势，当前两图为有效覆盖、平均执行时间，并有同版本数据表。按需读取首次有效写入，关联 M08 Window/Run 与 M09 事件。无权限时保留独立可用的组件健康范围。源整体健康、全局队列深度、消费速率、抓取/源时标、成功率和质量趋势等依赖缺失或尚未消费的投影。受控账号、别名、备份与恢复范围见 B15–B16。

**验收**　核探测过期/unknown、源端故障与组件独立、分页或局部授权、缺分母及无新写入。首写 `known/none/unavailable` 分开。时间线仅采用有证据的写入、Run 和事件时刻。条件换域或能力失效后清除诊断，回跳保持可用上下文。 [页面](../src/operations/OperationsPage.vue) · [取证流程](../src/operations/useOperations.ts)

## SYS-403 暂无访问权限

**需求与当前操作**　通用说明和安全恢复、公开顶栏，主动作按最新能力回可用用户区或说明。能力检查、退出或切换后仅以新会话可见结果呈现。

**验收**　有效会话缺能力走 403，目标对象信息不泄露。恢复前复查，能力接口失败时有公开路径，进入时标题可聚焦，手机按钮可完成操作。主卡按 S08-02 检查单层滤镜和强制色等实体回退，强制色现有差异见 B03。 [状态视图](../src/system/SystemStatePage.vue)

## SYS-404 页面不存在

**需求与当前操作**　覆盖 `/app` 子树未匹配地址，提供同样的安全恢复机制及明确的地址异常说明。能力检查失败单有「重新检查」和公共说明，属于应用外壳状态。

**验收**　公开浏览、有效用户、空/仅管理能力、会话过期、直接刷新失效地址各自可恢复。应用外路径及 Django HTTP 回退按宿主验证。M08 非法 ID 的地址刷新问题单列 B05。 [状态视图](../src/system/SystemStatePage.vue) · [应用壳](../src/App.vue)

## 三条验收路径

1. **用户观察**　注册 → 独立登录 → M01 同刻快照及筛选 → M02 C/T/S 分区 → M03 选站址期、M06 历史 → 关注 → 退出重登在 M07 复访。核同域、时间、撤权、焦点和可列表替代地图。
