## 结论与证据边界

- 原编号和分类保留。共 43 项，A 7、B 13、C 6、D 4、E 10、F 3。下表的 P1/P2 沿报告，指相应范围内的优先级。独立验收项的 P1 与正式基本路径准入分别判断。
- **文档证据**确认业务和设计要求。**前端静态证据**确认实际调用、显示、适配和边界。**F 与同源响应注入**只验证客户端行为。后端接口、数据库和权限的判断引用报告的处理器、无库验证和历史样例。没有在当前后端运行有库业务流程，也未连接正式数据。
- **C 类复核结果**　BG-001、006、016 有实际前端问题。BG-015 是文档枚举错误，代码已经发送 `aggregate`。BG-011 的模型复用存在误用风险，正式 UI 目前隐藏未披露的逻辑键。BG-020 的主要错误在文档，前端已区分撤权占位和 404；首选产品操作的拒绝清理另有欠覆盖路径。
- **优先确定契约**　普通分页一致性、图点和配对证据、导出范围/列/F 文件标识、工作区和动作资格、质量证据与隐匿、两种失联恢复，以及使用这些响应的机器契约。下列字段名和分支是提议，需前后端和对应业务方确认。
- 维持 S09-01、S09-02 和展示优先。正式总览基本路径为可搜索、可下钻的同刻列表。正式地图与全国趋势独立验收。治理从已有获权 Job 或登记模板起步。F 的玻璃、图表、地图、布局和互动照已确认设计保留。
