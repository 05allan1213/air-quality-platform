# S07 T09 正式性能与稳定性验证

## 验收口径

T09 的四项预算来自批准方案 §5。使用正式 WSGI 配置，在真实 PostgreSQL、Redis、Worker、唯一 Beat 与同源 HTTP 上运行。两轮热测分别采用 R1 → R2 → R3 → R4 和反向次序。五个普通用户各用真实 Session 和独立连接池，每个形状先预热 10 次，再采样 100 次，共 500 个样本。P95 是按耗时排序后的第 475 个值。单次耗时从开始发送到读取完整响应体。每条样本保留状态、响应字节、内容校验、会话起止和重叠区间。R2 的首页与后继页分层报告。B 补测沿用相同产品和查询，每形状五名用户各跑 10 次。[批准方案](../plans/S07_IMPLEMENTATION_PLAN.md)

**交付候选 `5c2073e` 的 V13、T09 实测为 PASS。** 两轮热测和一次独立诊断均从同一个交付包重建。B 也从该包独立重建并完成规定补测。两轮四项 P95 均满足预算，4,000 个计时样本与 400 个预热样本全部正确。历史超预算轮及调优后初始候选的收据继续保留。

## 重建与运行

使用候选 Git 提交的干净副本或经 manifest 校验的交付包，在锁定依赖准备完成且其他验收空闲时运行。实测文件顺序为 `compose.yaml` → `compose.offline.yaml` → `scripts/s07_isolation.yaml`。`compose.offline.yaml` 承载批准方案 §5.1 的正式 Gunicorn 配置，验证覆盖文件登记本轮实例、内部网络、卷与实际进程的隔离条件。Guard 生成空数据库、专属卷、Redis 和 Beat 锁文件，核对归属、双内网路由、数据库与 Broker 标记后再迁移。运行器为每轮固定一个空闲回环端口，重启时保留五个 Session 的原同源地址。应用退出后清理本轮资源。运行器记录配置文件、锁、迁移、源码摘要、独立构建镜像与实际 PID 1 argv。Gunicorn 配置固定为 `1 worker / gthread / 8 threads`。[启动与运维](../operations/S07.md)


### 从交付包复算

在解包根目录运行下列命令。`fields` 说明每个样本数组的列，时间为该批次相对单调钟的纳秒值。每个 `receipt` 保留对应原件路径、大小和 SHA-256。[机器证据](S07_T09.json)

```sh
python3 - <<'PY'
import json
from collections import Counter
from pathlib import Path

report = json.loads(Path('docs/verification/S07_T09.json').read_text(encoding='utf-8'))
for mode in ('heat', 'reverse'):
    run = report['modes'][mode]
    assert set(run['timed_requests']) == {'R1', 'R2', 'R3', 'R4'}
    for shape, batch in sorted(run['timed_requests'].items()):
        fields = batch['fields']
        warmup = [dict(zip(fields, row, strict=True)) for row in batch['warmup']]
        samples = [dict(zip(fields, row, strict=True)) for row in batch['samples']]
        assert len(warmup) == 50 and len(samples) == 500
        assert set(Counter(row['user'] for row in warmup).values()) == {10}
        assert set(Counter(row['user'] for row in samples).values()) == {100}
        assert all(row['http_status'] == 200 and row['correct'] for row in warmup + samples)
        durations = sorted(row['duration_ns'] for row in samples)
        p95 = durations[474] / 1_000_000
        assert p95 == run['shapes'][shape]['P95_ms'] <= report['budgets_ms'][shape]
        print(mode, shape, len(samples), f'{p95:.3f} ms')
b = report['host_supplement']

    print('B', shape, len(groups[1]), f'{p95:.3f} ms')
```
