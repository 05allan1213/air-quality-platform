## Findings 与处置

| ID | 影响 | 修订后的计划与可复现断言 |
|---|---|---|
| PR-01 · 高 | 滚动额度可在下一周期恢复，限定现场验证可能超过获准总次数。 | 在来源锁内按验证授权累计 PG 预留。额度 1 遇到 503、新手工 UUID、重投、重启、跨周期后，累计 HTTP 与预留均为 1。 |
| PR-02 · 高 | 已运行 Job 的冻结触发器会阻止撤权后清除旧名册。 | 给 CNEMC Job 设计受控、单向脱敏。部分和全部撤权后检查旧 Job、窗口和目录实物，分别测试共享目录仍有依据和已完全失权。 |
| PR-03 · 高 | 现有 `expected_codes` 同时用作应到名册和处理白名单，无法表达只获准处理一个站的一项指标且分母未知。 | 分别冻结对象×指标的处理选择与独立应到格。用全国 F 包仅授权甲站 AQI，观察规范化入口与持久项均只含该格，管理读为 `E=null、O=1、V=1`。 |
| PR-04 · 中 | A05 相邻 24 小时窗若互借 RunItem，会把后次补到的小时记成前次实到。 | 新到的 T 观测归实际取得它的 Run。用两个相邻窗口核 2 次请求、25 个唯一小时及 `24/23/23`、`24/24/24` 两份覆盖结果。各窗 V 仍随当前质量资格计算。 |
| PR-05 · 中 | 通用规范化支持源等级冲突检查，现有线格式路径只把 `AqiLevel` 放在行元数据。 | 正式适配器把可用源等级传入 AQI 规范化。分别验证已知标准冲突进入待核、未知标准保留获准源描述、A03 缺可选列仍能处理七项。 |
| PR-06 · 中，可选 A08 | 同城两站的趋势请求需要分别识别站码、归属期和业务窗。 | 新增单站选择并生成站级 `scope_key`。同城两站并行时核两个 Query、两个独立窗口、各自的站址期与错站零写入。 |
| PR-07 · 高 | 两个处理范围不同的 Job 可能共用 `E=null` 的窗口，首个 Job 的读权可能暴露另一个 Job 的格或计数。 | 在 Window 锁内比较冻结的对象×指标选择，异选择在建立第二个 Run 和预留前返回 `window_contract_conflict`。管理读逐格核现行权利。并发测试分别核同选择合窗和异选择拒绝。 |

详细契约与定向回归位于[接入计划 §3–5](../plans/CNEMC_IMPLEMENTATION_PLAN.md)。
