# S04 用户查询与收藏 API

所有路径以 `/api/v1/` 开头。使用同源数据库 Session，写请求还须带当前 Cookie 对应的 `X-CSRFToken`。先读 `auth/csrf/`，登录后重新取令牌。业务请求读取 PostgreSQL 中现行且获准的记录。响应采用 `Cache-Control: private, no-store`。

| 方法与路径 | 访问方式 |
|---|---|
| `GET overview/national/` | 默认正式产品为 `cnemc/city-list-hour`。可指定 L `product`、精确 `at` 或选时上限 `as_of`、`standard_series` 和小时 `window_definition`。服务在可读 L AQI 中先定 `snapshot_at`，再按可披露目录做 `q`、`geography` 筛选。变更筛选时传回 `at=snapshot_at`。默认按城市 ID，每个城市一行。`order=aqi_desc` 还需显式的已确认标准。 |
| `GET cities/{city}/` | 指定 C `product`，可传 `at` 或 `as_of` 及 AQI `standard_series`。`slots` 中的七项共用一个 C 观测时刻。缺项为 `unavailable`。AQI 可有多个具名标准系列。`links` 包含当前授权下可访问的历史和其他产品入口。 |
| `GET cities/{city}/trend/` | 指定 T `product`，可选 `anchor` 和 `standard_series`。`anchor_basis` 说明锚的来源，`points` 按小时返回 `[anchor−23h,anchor+1h)` 的可见点与空槽。 |
| `GET cities/{city}/stations/` | 指定同源 S/H `product`、可选目录时刻 `at`，通过返回的 `link` 选定真实 Station 和 SiteEpoch。访问目录需要独立的 `catalog` 权。 |
| `GET stations/{station}/` | 指定 `product,site_epoch`，可用 `as_of,indicators` 限定最近值。省略 `site_epoch` 则列可披露的站址期选择。`identity` 中的目录字段按权投影。站址名称、代码和状态按 `as_of` 判目录权。已关闭的站址以该期最后一刻判权。只有历史目录权的期可以保留内部 ID，此时目录字段为空、状态为 `unknown`。已知内部 ID 且有规范值权的 H 查询可以单独读值。`history` 中的链接沿用产品及站址期。 |
| `GET observations/query/` | 通用明细要求 `product,mode,indicators,report_kind,window_definition`，城市产品传 `cities`，站点产品传 `site_epochs`。可选 `source`、`unit`、`standard_series`、`quality`。原 `observations/current/` 保留精确小时和地方日报入口。 |
| `GET/PATCH me/` | 返回本人 `username,first_name,last_name`。PATCH 只接受名字字段。 |
| `POST auth/password/` | JSON 只传 `old_password,new_password`。成功返回 204，须用新密码重登。账户在其他设备的旧 Session 随后同样失效。 |
| `GET/POST me/favorites/` | 页内批量求本人意图的当前授权摘要。POST 接受 `kind`（`city` 或 `station`）、`target_id,product`。首次 201，重复 200。相同目标的另一首选产品返回 `409/favorite_exists`。 |
| `GET/PATCH/DELETE me/favorites/{id}/` | 复访稳定实体，PATCH 接受新的 `product`。DELETE 204，包括已处置目录留下的本人占位。其他主体的该路径返回 `404/not_found`。 |

H 和正式产品使用默认数据域。F 每次传具体产品 ID 和 `scope=synthetic`。收藏列表、直接详情、改选、删除也需保持域一致。同一站点的期列表先按可披露的起始日期排序，日期为空的期排在末尾，按内部 ID 排序。用户应跟随服务返回的导航链接，其中的产品 ID 属于目标产品。所有 `at`、`anchor`、`start/end` 和 `as_of` 均为带偏移的 ISO 8601 时间。按产品来源的小时边界解释小时快照。列表型参数用一个查询键和逗号分隔的值。

### 复用明细

以下为本人已登录的同源客户端传给 `GET /api/v1/observations/query/` 的参数示例。用目录返回或操作者已经核实的 ID 替换变量。

```python
params = {
    "product": product_id,
    "site_epochs": epoch_id,
    "mode": "window",
    "indicators": "CO,PM2.5",
    "report_kind": "hourly",
    "window_definition": "hourly_label_unspecified",
    "start": "2024-01-01T00:00:00Z",
    "end": "2024-01-02T00:00:00Z",
    "page_size": 50,
    "scope": "synthetic",
}
```

显式窗为半开区间，传 `start,end`。`latest_valid` 去掉这两个键，可传独立的 `as_of`。每个产品、对象、指标、窗口、单位与标准系列各取一个当前可靠修订。每行的 `age_seconds` 用本次 `evaluated_at` 减实际 `observed_at`。`fetched_at` 来自产生当前修订的回执，血缘不明时为 null。`freshness`、来源状态缺乏独立依据时为 `unknown`。`value` 是十进制定点字符串。`quality=all` 可读取获权的缺测、删失、待核及争议状态。争议行隐藏数值。使用 `key,revision,qualification_version` 对齐不同视图。来源、署名、版本、单位及标准随行保留。

普通明细每次最多 5 个对象、7 个指标、30 天，`对象 × 指标 × 小时槽 ≤ 3600`。默认每页 50 行，上限 100。续页原样保留条件并传 `cursor=page.next_cursor`。游标有效期一小时。全国排名续页会检查上一页末城的可见性、修订、资格和排序键。动态数据中，其他城市可能在两次请求间移过末行。需要完整静态顺序时，在修订稳定后从首页重新读取。

全国的 `summary_eligible_city_count` 是已获准计算和展示汇总的城市数。全部可见城市均获汇总许可时才能返回 `covered_city_count`。`groups` 按已确认标准给出 `ranked_city_count` 和等级分布。未知标准可进入有权的城市覆盖，不生成排名。整项无汇总权时，普通列表的 `summary.state` 为 `unavailable`，排名入口返回 403。 没有登记城市代码时，覆盖全域的规范留存和逐值展示许可可返回 `200/no_data`。显式请求保留 `at`，自动选时的 `snapshot_at` 为 null。全域同时有明确的计算、展示汇总许可时，空排名的 `ranked_city_count` 为 0。

| 响应 | 客户端处理 |
|---|---|
| `200/no_data`、`200/no_coverage` | 保留显式空窗。后者还要求可披露的独立目录证据。 |
| `400/invalid_request`、`query_too_large`、`invalid_cursor` | 检查参数、拆分查询或回到首页。 |
| `403/not_authenticated`、`csrf_failed`、`permission_denied`、`use_denied` | 重登、重新取 CSRF 或按相应用途停止显示。 |
| `404/not_found`、`409/page_changed`、`429/rate_limited` | 私有项不可访问、从首页刷新、稍后重试。 |
| `503/database_unavailable` | 等本地数据库恢复后由会话重新发起请求。 |

### 升级与回退

本地升级运行 `python backend/manage.py migrate`，然后核对 `migrate --check` 和 `makemigrations --check --dry-run`。新增 `accounts.0001_initial` 创建收藏表、所有者/域索引及每人每目标唯一约束。旧账户、Session、观测键、修订和任务账本沿用原表。如需回退应用，优先停止新入口并保留表。反向迁移会删除全部收藏意图。阶段验证命令、冻结指纹和逐项收据见 [S04 工程交接](../verification/S04.md)。
