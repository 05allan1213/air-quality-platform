# S05 操作手册

S05 提供同层历史比较、浓度研究统计、支撑明细、私有分析方案和同步 CSV。方法版本为 `s05.v1`，CSV 格式为 `s05.csv.v1`。正式接口统一使用数据库 Session。对 POST、PATCH、DELETE 使用同一 Session 的 CSRF token。沿用 S04 的 [登录与 CSRF 流程](S04.md)。

## 启用与升级

1. 在待升级的应用版本及经授权的 PostgreSQL 上运行 `python backend/manage.py migrate`。`accounts.0002_saved_query`、`accounts.0003_export_ticket` 是从 S04 增加的迁移。随后执行 `check` 与 `migrate --check`。升级前先在隔离库复验。
2. 验证使用 `CNEMC_MODE=off`。研究、下钻和下载只读本地合规观测。当前真实 CNEMC 研究与导出仍缺适用许可。真实 H 的研究也须先确认原件和当次用途。
3. 保持 Web、Worker 使用同一代码和迁移。Worker 启动的 `s02_dispose_due` 包含有界票据/基线清理。单个 Beat 周期每 60 秒将 `observations.expire_research` 投递至 `s02.history`。停止 S05 服务时可先关闭新增入口并保留私有意图。反向迁移会删除 S05 私有表，应仅在已批准的处置或隔离验证中执行。

## 接口

路径均相对于 `/api/v1/`。

| 方法与路径 | 请求与响应 |
|---|---|
| `POST analysis/compare/` | `method=compare`，选择同产品两个以上实体的同一指标。返回每列覆盖、共同覆盖、配对值及条件允许的共同样本结论。 |
| `POST analysis/statistics/` | `method=statistics` 或 `pearson`。单列可以选择 `hour/day/month/season`。Pearson 固定单实体两项浓度。可附分布、箱线信息、热图、IQR 候选和图表。 |
| `POST analysis/details/` | 携父查询及 `input_version`，可加 `bucket`、`support`、`page_size` 和 `cursor`。独立明细可用 `method=detail` 发起第一页并取得版本。 |
| `GET/POST me/saved-queries/` | 分页列出本人方案，或以父查询和 `title` 创建。 |
| `GET/PATCH/DELETE me/saved-queries/{id}/` | 查改删本人方案。PATCH 带 `intent_revision`。更改目标、窗口或方法时可提交新的完整条件。 |
| `POST me/saved-queries/{id}/run/` | 空请求体 `{}`。以当前权限复访固定日期，返回 `current`、`data_changed`、`baseline_unavailable`、`method_changed` 或 `target_unavailable`。 |
| `POST me/exports/` | `kind=detail` 或 `aggregate`。`groups` 中提交完整父查询和版本，可选 `fields`。201 签发，获准零行返回 `200/no_data`。 |
| `GET me/exports/`、`GET/DELETE me/exports/{id}/` | 查看本人安全元数据或取消票据。 |
| `GET me/exports/{id}/download/` | 以本人仍有效的 Session 领取。成功返回 `text/csv; charset=utf-8`，附件名 `air-quality.csv`。 |

私有资源读取、删除和复访默认使用 `formal`，F 使用 `?scope=synthetic`。列表接受 `page_size` 与 `cursor`。服务器用 Session 绑定 owner。产品、目标和范围必须显式指定，空窗不会改取新的时段。

### 用同一组 F 条件核对比较、明细和导出

`product` 与 `site_epochs` 替换为隔离 F 库返回的实际 ID。示例对应 `tests/test_s05_statistics.py` 的 `test_v04_threshold_uses_the_same_samples_and_drilldown`。

```json
{
  "selection": {
    "product": 1,
    "source": "test.s05.v04",
    "scope": "synthetic",
    "site_epochs": [1, 2],
    "indicators": ["PM2.5"],
    "units": {"PM2.5": "µg/m³"},
    "window_definition": "hourly_label_unspecified",
    "standard_series": {"PM2.5": "not_applicable"},
    "start": "2024-01-01T00:00:00Z",
    "end": "2024-01-02T00:00:00Z"
  },
  "method": "compare",
  "method_version": "s05.v1",
  "grain": "day"
}
```

两站各有 18 个有效小时、共同有效 12 小时时，`E=[24,24]`、`V=[18,18]`、`E_common=24`、`P=12`，返回 `ranking=null`。取响应的 `selection`、`method`、`method_version`、`grain` 和 `input_version`，加 `support="paired"` 提交到 `analysis/details/`，得到 24 条支撑行。逐桶核对时原样复制返回的 `drilldown` 或 `observed_drilldown`，继续携带完整父查询。比较中的单列桶带 `bucket.pos`，整期 `paired_drilldown` 返回双方。热图的 `bucket.local_hour` 以来源时区筛选，夏令时回拨可匹配到两个实际时刻。`grain=hour` 按实际时刻分别出桶。续页原样携带 `page.next_cursor`，页长最大 100。`observed` 用于检查实到及质量，`effective` 用于可靠样本。图表点过多时按时间分桶，原始支撑行仍可分页。

在有相应导出许可的 F 库中，可以直接用响应构造准备请求。以下 `jq` 读取比较接口的 JSON 响应。将输出通过同一 Session POST 到 `me/exports/`，再使用 201 响应的 `id` 领取。两次准备分别检查各自的字段许可。在同一组 V04 数据补登记所列明细与汇总字段后，两次准备均返回 201、下载均返回 200。明细 CSV 有 36 行实到记录，汇总 CSV 有 4 行，分别为两列日桶与两列共同样本记录。各行与比较响应的 `input_version` 一致。详见验证报告中的运维示例收据。

```sh
jq '{kind:"detail",groups:[{selection,method,method_version,grain,input_version}],fields:["qualification_version"]}'
jq '{kind:"aggregate",groups:[{selection,method,method_version,grain,input_version}],fields:["mean_difference"]}'
```

`fields` 指定额外白名单列，必需的溯源和解释字段总会包含。明细可加 `qualification_version`、`report_kind`、`fetched_at_basis`。汇总可加 `median`、`minimum`、`maximum`、`minimum_at`、`maximum_at`、`rank`、`pearson`、`mean_difference`、`received_ratio`、`valid_ratio`。最多两独立组、五个目标、七种指标和 12,000 候选格。授权后最多 10,000 数据行和 4 MiB；JSON 预算 1 MiB。票据最长 15 分钟，相关授权截止可缩短期限。每账户至多 12 张活跃票据，每分钟至多签发 5 张。CSV 在内存编码，PostgreSQL 留存短期清单和摘要。缓存应遵守响应 `no-store`。

## 用途授权与数据边界

- 通过 `observations.policy.register_grant` 受控登记。登记人须有 `manage_grants`。按产品、受众、范围、指标、字段、期限和署名建立依据。旧操作员分析使用 `operator`，研究和导出入口使用 `local_authenticated`，包括管理员通过这些入口发起的请求。客户端无法选用受众。
- 分析需要分别覆盖 `retain_normalized/platform`、`analyze/local_authenticated` 和 `display/local_authenticated` 的相应用途。研究派生字段为 `catalog`、`research_coverage`、`research_summary`，逐名授权。逐值展示需 `normalized`、`provenance`。独立明细导出与汇总导出分别用 `export`、`export_aggregate`，汇总还须分析许可。用途字段的完整交集由服务计算，CSV 需相应 `csv_<列名>` 以及 `export_manifest`。保存可用于比较的基线需 `statistics_baseline` 留存依据。
- F 自制测试按 C、S、H 形状独立验证。真实 S/S 要有同城站址证据。UCI H/H 只认可已核实的同研究集、同城报告身份与 `uci501-edges-v1` 两站两窗。H 导出须单独判断。L、T 和 D 使用各自产品和报告口径。获准 D 明细要求整个来源地方日 `[00:00, 次日 00:00)` 与 `local_daily`，CSV 记录报告日期。未知标准 AQI 的源描述需要 `source_description` 的留存和展示许可。未知研究节奏返回空分母，明确零分母单独返回。真零、缺测、删失、争议各自保留，异常候选保留原质量状态。
- 同一凭据必须覆盖该用途所需的全部字段。去除一个输入的导出许可会使整份双组文件拒领。当前完整授权依据变化会作废相交票据，未来许可生效点可缩短截止。对于需要额外分发条款、而系统无法执行相应限制的来源，保持拒绝。撤留存时按依赖处置清单与基线，用户仍可删除自己的意图。

### V16 的真实 H 复现

先检查已获准私存的 `S02_UCI_ZIP`。目标文件是 `PRSA2017_Data_20130301-20170228.zip`。首次取得时，在项目根运行以下命令。`tmp/` 同时受 Git 和 Docker 构建上下文排除。外包中的其他文件无需解压。数据集的作者为 Chen, S.，UCI ID 为 501，许可为 CC BY 4.0。复现前核对官方署名、许可与使用范围。[UCI 数据集](https://archive.ics.uci.edu/dataset/501/beijing%2Bmulti%2Bsite%2Bair%2Bquality%2Bdata) · [DOI](https://doi.org/10.24432/C5RK5G) · [许可原文](https://creativecommons.org/licenses/by/4.0/legalcode.en)

```sh
umask 077
mkdir -p tmp
uci_dir=$(mktemp -d tmp/s05-v16-uci-XXXXXXXX)
curl --proto '=https' --fail --silent --show-error \
  'https://archive.ics.uci.edu/static/public/501/beijing%2Bmulti%2Bsite%2Bair%2Bquality%2Bdata.zip' \
  -o "$uci_dir/outer.zip"
S02_UCI_ZIP="$uci_dir/PRSA2017_Data_20130301-20170228.zip"
.venv/bin/python - "$uci_dir/outer.zip" "$S02_UCI_ZIP" <<'PYTHON'
from hashlib import sha256
from pathlib import Path
import sys
from zipfile import ZipFile

outer, target = map(Path, sys.argv[1:])
with ZipFile(outer) as z:
    if z.namelist().count(target.name) != 1 or z.getinfo(target.name).file_size != 7959991:
        raise SystemExit("Unexpected inner member or size")
    data = z.read(target.name)
if sha256(data).hexdigest() != "d1b9261c54132f04c374f762f1e5e512af19f95c95fd6bfa1e8ac7e927e3b0b8":
    raise SystemExit("Check official release and ZIP layer")
with target.open("xb") as f:
    f.write(data)
PYTHON
```

已有正确内层原件时直接执行下列两项。需要本机 `redis-server`、Unix socket、`.venv` 和已有的 `postgres:16-alpine`、`air-quality-platform-app:local` 镜像。运行器各自创建带随机标识的 PG 容器和数据库，写入前核对数据库名、角色、socket 及运行标识。V16 的导入容器只读挂载当前源码和 socket 目录，使用标准输入和私有 tmpfs。正式 `stage_uci` → `submit` → Redis → Celery Worker → `consume` 完成导入，Worker 清除暂存文件。Web 在另一个进程通过回环 HTTP 接受查询。

```sh
.venv/bin/python scripts/verify_s05.py -- scripts/s05_v16.py < "$S02_UCI_ZIP"
.venv/bin/python scripts/verify_s05.py -- -m pytest -q \
  tests/test_history_import.py tests/test_history_policy.py \
  tests/test_observation_rules.py tests/test_observation_access.py \
  tests/test_s04_selection.py tests/test_s04_station.py tests/test_s04_noninterference.py \
  tests/test_s05_rights.py tests/test_s05_selection.py tests/test_s05_statistics.py
```

V16 先核冻结指纹，再以隔离登记账号调用 `register_uci` 和 `register_grant`。S02 的档案获取、加工、留存及逐值使用按原受众登记。新增三种研究用途，每种按 2 站 × 2 个地方时半开窗 × 6 项浓度逐条登记，`geography=beijing`。覆盖 `[2013-03-01, 2013-03-03)` 和 `[2017-02-27, 2017-03-01)`。指标为 PM2.5、PM10、SO₂、NO₂、CO 和 O₃。项目将每次复验的研究授权设为数据库时钟起两小时，规范留存用 `recoverable` 到期模式，隔离库在运行结束即销毁。CC BY 4.0 是授权依据，项目自设的运行期限只适用于本次登记。

| 用途与受众 | 单条 grant 完整列明的字段 |
|---|---|
| `retain_normalized/platform` | `normalized, provenance, catalog, research_coverage` |
| `analyze/local_authenticated` | `normalized, provenance, catalog, research_coverage, research_summary` |
| `display/local_authenticated` | `normalized, provenance, catalog, research_coverage, research_summary` |

登记保留数据集 DOI、许可地址、作者、选站选窗、假定时区、小时标签、单位换算及研究算法说明。登录读者没有操作员权限。验证器检查旧 operator 入口、窗外访问、CSRF、不匹配的父版本与两种无导出许可的请求。控制台给出 `tmp/s05-evidence/<run>/`。其中 `V16/use-grants.json` 为数据库登记回读，`V16/h-reconcile.json` 保存三方各自算得的聚合、父版本和分页计数。逐小时样本只作内存断言。复验数值及原件来源凭据见[验证报告](../verification/S05.md)和[机器收据](../verification/S05_evidence.json)。

## 故障处理与复验

| 响应 | 操作 |
|---|---|
| `403/not_authenticated` 或 `csrf_failed` | 验证登录、同 Session token 和当前 Cookie。 |
| `403/use_denied` | 按当前操作核产品、对象、日期、字段和受众。适用撤权和限制已入账时重新确认权限。 |
| `404/not_found` | 检查本人 ID 和 `scope`。已取消或处置的票据按不存在处理。 |
| `409/input_changed` 或 `method_changed` | 重新执行统计/明细获取当前版本，复访方案时确认方法，重新准备 CSV。 |
| `410/expired` | 在许可仍有效时重新准备。 |
| `422/incompatible_series` | 核对产品、层级、同城证据、期间、单位、窗口与标准。 |
| `429/rate_limited` | 清理无用票据或等待频率窗口。 |
| `503/database_unavailable` | 检查 PG 就绪及持锁任务，待恢复后发起新请求。导出锁等待 1 秒、单条 SQL 5 秒、事务应用预算 10 秒。 |

用本地 Python 环境及已有 `postgres:16-alpine` 镜像创建独占、无网络的 PG，Redis 验证使用系统 `redis-server` 和 Unix socket。命令输出的本地收据可按运行 ID 查找。迁移对账默认从本地 Git 提交 `98548111e364654253c7957aaa68c5388d0914d0` 导出 S04 源码并验证冻结指纹。也可在 `migration` 后加 `--s04-archive PATH` 指向已核对归档，运行器校验归档和源码两组指纹。

```sh
.venv/bin/python scripts/verify_s05.py -- -m pytest -q
.venv/bin/python scripts/verify_s05.py -- scripts/s05_runtime_checks.py fresh
.venv/bin/python scripts/verify_s05.py -- scripts/s05_runtime_checks.py migration
.venv/bin/python scripts/verify_s05.py -- scripts/s05_runtime_checks.py s04-http
.venv/bin/python scripts/verify_s05.py -- scripts/s05_runtime_checks.py async
.venv/bin/python scripts/verify_s05.py -- scripts/s05_runtime_checks.py restart
```
